# 产品设计方案 v2：为海外双语孩子调优

日期：2026-10-25。对象：Cindy，8 岁，在国外读二年级，国内读过幼儿园；中文口语流利，识字和写字吃力，写字容易挫败、敷衍。

本文分四部分：现状优缺点、竞品对照、按七条原则的功能设计、本轮已落地和后续建议。竞品信息只采用官方页面和应用商店的公开描述，不代表做过付费版的完整实机体验。

---

## 一、现状评估（v1）

### 优点
- **防猜测做得扎实**：识字题不给图、不给拼音，干扰项用形近字；答错或看提示后，这个字本轮不算独立认对；独立认对要在两种题型里都第一次答对。规则都有单元测试。
- **认字和写字已经分开**：每天 3–5 个新字、1–2 个重点写字，家长可以调；描红只记"练过"，不冒充"会默写"。
- **奖励有上限，也有明确收尾**：同一天重复做不重复给星星；完成后首页会明确告诉孩子"今天的任务完成了"；挑战榜只和自己的历史比，不虚构同学。
- **轻量**：纯静态网页，离线素材齐全，平板浏览器直接打开就能用，没有账号，也不收集数据。

### 不足（对照七条原则）
| 原则 | v1 的缺口 |
|---|---|
| 识写异步 | 写字仍绑在当天的新字上；没写完的字不会回来，写字没有自己的进度线 |
| 诊断先行 | 固定 6 个字，只用来定难度；已经认识的字下次还会从头教 |
| 分层记忆 | 认字有"小芽/在长大/记得牢"，但写字只有"写过"，分不出是照着描还是凭记忆写 |
| 温和容错 | 识字有提示；**写字没有退路**：描不完就不能进入下一站，最容易出现敷衍乱划或放弃 |
| 生活连接 | 只有一句通用的"说给家人听"，和海外的真实生活场景无关 |
| 有界奖励 | 收尾页只说"今天到这里"，看不到明天要做什么、写字状态如何 |
| 家长看板 | 只有最近的混淆字；笔画错误虽有计数但没有展示；看不到卡在哪一笔、哪类偏旁、是否常常需要帮助 |

## 二、竞品对照与差异化

| 产品 | 公开资料可确认的做法 | 平衡趣味与效果的方式 | 对 Cindy 的取舍 |
|---|---|---|---|
| 叫叫识字 | 动画、想象识字、主角冒险剧情串联游戏；应用商店介绍为"每天 10 分钟、每天 6 个汉字"，12 个主题星球、480 个小游戏 | 用剧情和收集卡驱动每天回来 | 剧情化值得借鉴；每天 6 字对写字困难的二语孩子偏多，我们保持 3–5 字认、1–2 字写 |
| 悟空识字 | 每日新字量可调，故事关卡，薄弱字复习 | 关卡推进加复习 | 吸收"可调量"和"薄弱字回炉"；不做按关卡解锁的刷题 |
| 洪恩识字 | 按字源和字义做动画；认、懂、用、写、读；配有用已学字写的绘本 | 意义理解在前，书写在后 | 吸收"图义绑定"；不伪造字源，抽象字用例句情境 |
| Duolingo ABC / Khan Kids | 短任务，逐级加支架，按掌握程度推进 | 每次只有一个主要动作，困难时降级 | 吸收支架阶梯，把它用到写字上 |

**国内产品的共同前提**是孩子每天都生活在汉字环境里，App 只是补充。Cindy 的环境相反：口语很强，但几乎看不到汉字；当地学校用拉丁字母；写汉字没有日常需要。所以改良方向是：

1. **用口语带识字**：她听得懂的词是最大资产。题目都从"听词选字"开始，例句贴近家庭口语。
2. **认得比会写重要，写字要有退路**：二语孩子写字挫败感更强。写字单独排进度、可以降级，未完成不算失败，只是"明天接着写"。
3. **主动制造生活里的汉字**：海外很少能"偶遇"汉字，所以要去亚洲超市、中餐馆菜单、春联红包、视频通话这些真实场景里找。
4. **不用排名和速度刺激**：海外孩子本来就容易把中文当成"额外的作业"。奖励是收集和装扮，而且每天有上限。

## 三、按七条原则的功能设计

### 1. 识写异步：任务生成器
- **认字线**：每天新字数为家长设定的 3/4/5；到期复习最多 5 个；中断几天不累计新字欠账。
- **写字线（v2 新增）**：每天重点写 1/2 个字，**优先安排前几天没完成的字**，余下的从今天的新字和复习字里补。
- 写字只在三种情况下算完成：描红完成、凭记忆写完成，或家长调整计划。只看了笔顺或跟着提示写完，第二天会再排。
- 家长改设置只影响之后的日子，当天已开始的目标保持不变。

### 2. 诊断先行：自适应摸底（v2 新增）
- 最多 9 题，**从最简单的一档开始**：答对升一档，答错或点"不确定"降一档；**连续三次不确定就提前结束**，避免第一次就挫败。
- 起点难度按各档答对数量决定。
- **答对的字直接记为"已认识"，跳过新学**，并安排在**第二天复习确认**（四选一有 25% 可能是蒙对的）。确认答错，就回到正常学习路线，下次复习前会先重看一遍学习卡。
- 结束时告诉孩子"你已经认识：……"，让她第一次打开就有收获感。

### 3. 分层记忆
- **认字**：小芽 = 刚学过（短期）→ 在长大 = 两个不同日期独立认对（巩固中）→ 记得牢 = 至少三天独立认对（长期）。复习间隔为 1/3/7/14/30 天，独立认对失败就退回小芽。
- **写字（v2 新增）**：练习中 → 描红完成 → **能独立写**（在描红之后的某一天，不看描红凭记忆写出来）→ 写得牢（两天凭记忆写出）。
- 关键规则：**凭记忆写只能出现在描红后的另一天**，这样能区分"照着描"和"真正记住"。
- 字库卡片和汉字档案同时显示认字和书写两条进度。

### 4. 温和容错（v2 重点）
- **识字**：答错一次会提示"再看看字形"；连续答错两次或主动点"我不确定，找线索"，会显示拼音、部首和词语，本次记为"借提示完成"。不扣分，这个字会更早回来复习。
- **写字降级阶梯**：凭记忆写 → 描红 → 跟着提示写（写错一次就亮出正确的笔画，判定更宽松）→ 一笔一笔看（只看不写）。
  - 每一级都可以主动点"换成……"；一次写错 5 笔后，系统会主动提示可以换简单方式。
  - 凭记忆写时点"想不起来，看笔顺"，等于切换到描红，避免"偷看后算凭记忆写"。
  - 每一级都有"今天先写到这里"，可以直接进入下一站，当天认的字照样算数，这个字明天再写。
- 文案统一用"换一种方式，一样是认真"，不用"失败、错误"等字眼。

### 5. 生活连接：生活寻字与小岛护照（v2 新增）
- 首页每天给一张生活任务卡，只用**她已经学过的字**，场景针对海外家庭：
  - 超市亚洲货架（米、面、鱼、蛋……）
  - 中餐馆菜单
  - 家里的便利贴（门、窗、书）
  - 公园散步
  - 机场、唐人街或中文学校的标识
  - 和爷爷奶奶视频
  - 春联、红包、月饼盒
  - 坐车时看路牌
- 优先用当天的新字；**同一天任务固定**，刷新也换不到更简单的。
- 做到后点一下，就在"小岛护照"盖一枚对应场景的印章，每天最多一枚。**不加星星**，避免为了奖励虚报。
- 不要求拍照或录音，保护隐私，也不增加家长负担。

### 6. 有界奖励与明确收尾
- 星星只来自当天的有效学习：独立认对 +3，借提示完成 +1，写完重点字 +2；同一天重复做不重复给。
- **收尾仪式（v2 补充）**：完成页列出今天的清单：认字完成、书写写好了或明天接着写、明天会回来几个老朋友（按每天最多 5 个计算）、生活寻字是否已盖章。最后建议"看看远处，活动一下手指"。
- 当天完成后，首页按钮变为"去看看我的小岛"，没有"再来一轮"。只有暂停中的探险才会显示"继续"。

### 7. 过程导向的家长看板（v2 新增"她真正卡在哪里"）
- **记忆分层**：刚学过、正在巩固、长期记住各有多少个字。
- **笔顺卡点**：精确到"森 · 第 1 笔，累计写错 5 次"，并附陪练建议：先一起空书这一笔，说说起笔在哪里、往哪个方向走。
- **容易混的偏旁**：把混淆记录按偏旁归类，例如"「氵」和「日」"或"同为「木」旁的字"，建议把两个字并排写大来比较。
- **求助与降级信号**：最近 7 次探险借提示几次、书写主动换简单方式几次、哪些字留到之后再写、哪些字单次书写偏久（超过 60 秒）。
- 页面明确写着"这些是陪练线索，不是成绩"。

## 五、v3 简化：对《产品简化设计方案》的分析与落地（2026-10-25）

### 采纳了什么
那份方案的核心判断是对的：问题不是功能少，而是孩子要先理解一套系统才能开始学。本轮按它的主线做了减法：

| 方案建议 | 落地 |
|---|---|
| 首页只突出"开始" | 首页只剩问候、小岛、一句真实的今日概要（"今天再认 2 个旧字，认识 3 个新字，写 1 个字"）和一个大按钮；有未完成任务时按钮是"继续"，完成后是"看看小岛" |
| 导航减到三处 | 顶部只有"今天 / 我的小岛"，右上角一个低调的"家长"文字入口；学习地图、字库、故事、偏旁游戏收进"我的小岛 → 自由探索" |
| 学习时收起导航 | 学习、摸底、练字、收尾页隐藏导航、音乐和家长入口，只留"← 休息一下"和阶段提示（认一认 / 写一写 / 换个词再认） |
| 一屏一个问题 | 识字页固定为：指令 → 重听 → 四个选项 → 反馈 → 一个下一步；去掉所有"站点"命名、小兔旁白和解释性文字 |
| "我还不确定"常驻 | 答题前只有这一个文字按钮；答对后才出现"继续"，不再显示灰色按钮，也不再强制等 1.3 秒 |
| 写字由系统带路 | 书写页去掉侧栏；加载后自动示范一遍，然后直接进入描红；底部只有"再看一次 / 换成更简单的方式 / 今天先写到这里" |
| 休息不弹确认 | 进度本来就随时保存，点"休息一下"直接回首页 |
| 结束页用真实记录说话 | "今天练习了：木 林 森 / '林''森'换个词也认对了 / '木'跟着提示找到了 / '林'按笔顺写出来了"，星星只在这里出现一次 |
| 排行榜改成成长 | "我的小岛"里先看四张成长卡（见过多少字、这周还记得几个、过了几天还记得几个、能凭记忆写几个），"详细记录"一点才展开，表头改成孩子能懂的"自己认出 / 借了提示 / 写了" |
| 家长页先看三件事 | 顺序改为：今天练了什么 → 哪些需要帮助 → 明天怎么陪（一句具体建议，优先来自笔顺卡点，其次混淆字，再次生活任务）→ 她真正卡在哪里 → 设置 |
| 文案 | 按方案的对照表替换：开始、再认一认、换个词再认、我还不确定、继续、过了几天还记得 |

### 没有照搬的地方
1. **进度显示**：方案建议不显示"第 12/27"。我去掉了数字，但保留了一条真实的进度条。8 岁的孩子需要知道"快结束了"，这不是虚假激励。
2. **摸底改为可选**：方案针对的是 v1 的固定 6 题。v2 的自适应摸底本来就能跳过，连续三次不确定会提前结束，所以保留，只把开场说明缩短成两句话。
3. **生活寻字和书写降级阶梯**：方案写于 v2 之前，没有覆盖这两项。保留，但生活寻字只在当天任务完成后才出现在首页，不再和"开始"抢注意力。
4. **答对后的反馈**：方案建议"简短、具体"。实际试用时文字句子仍然偏多，改成一个大的圆形对勾加两个字（"对了" / "找到了"），答错是问号圆点加"再看看"；正确的词由语音念出来，而不是写出来。

### 验证边界
- 在本机浏览器走完：摸底跳过、认字答错再答对、描红自动示范、整轮结算、成长卡、详细记录、家长页三段顺序。
- 仍未在真实平板上做手写与可达性测试；方案第 10 节的"连续 3 次观察"要由家长在 Cindy 身上做。

## 六、对《Google 与字节产品设计方案》的分析与落地（2026-10-25）

### 判断
文档把两种视角分开：Google 式"可预期的每日助手"和字节式"每天一集的小故事"，并建议对 Cindy 先用前者的结构、再加后者最轻的一层。这个结论和 v3 已经做的方向一致——v3 完成后，文档第 3 节（首页一个入口、固定学习布局、学习时收起导航、结束页用真实记录、家长页先看三件事）已经基本落地。本轮只补它仍然指出、而 v3 没做到的四件事，字节方案只取"一句情境"这一层，不做故事分支。

| 文档建议 | 本轮落地 |
|---|---|
| 3.3 学习字卡"只交付字音、字形和一个常用词"，句子在同一位置随后出现 | 学习卡分两步：第一步拼音、大字、一个词、情境图，自动读字音和词；点"继续"后在同一张卡上出现第二个词和例句，自动读句子；再点"继续"才进入认字 |
| 3.3 书写"底部提供'再看一次'和必要时出现的'帮帮我'" | 写字页初始只有"再看一次"；写错 2 笔（凭记忆写为 1 笔）或 45 秒后，才在原位出现"帮帮我：换成「跟着提示写」"和"今天先写到这里"。一笔一笔看模式直接显示 |
| 3.3 结束页"昨天的'木'，今天也认出来了" | 结束页区分新字和复习字：新字"换个词也认对了"，复习字"之前学的'木'，今天也认出来了" |
| 7 "首页一句生活情境，例如'今天和小兔去公园'" | 首页按钮上方一行"今天去 🌳 森林来信"，取自今天第一个新字所属的主题岛；不做剧情，不影响测验 |
| 6.3 "字体是否规范" | Android 没有楷体，目标字会变成黑体。打包了霞鹜文楷（OFL 许可）截取 500 字的网页字体，110 KB，用于大字和字库卡片；iPad 和电脑也统一用它 |

### 没有采纳的
- 4.2–4.5 的故事模板、"换一个故事"、情境内互动：内容制作和审核负担大，而且文档自己也指出可能"记住剧情没记住字"。先观察一句情境是否足够。
- 3.6 "你发现左边的三点水了"这类具体文字反馈：上一轮用户要求反馈改成图标加两个字，保持不变；偏旁信息在家长页"容易混的偏旁"里。
- 8 的对照试验：单个孩子做不了对照，按 8.2 的指标由家长观察即可。

对当天所有改动（含另一会话加入的中途结算、每日配对、航行地图、字库搜索）做了一次只看证据的复查，只改确定有问题的地方：
