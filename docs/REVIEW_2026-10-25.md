# 汉字小岛 · 只读评审（2026-10-25，本地版 9f47d9f）

评审对象：Cindy 的汉字小岛，给 8 岁海外华裔孩子的每日认字写字网页。访问 http://localhost:4180（本地最新版，比线上多"勋章、分层完成页、下一个目标、第一笔提示"四项）。平台：Web / PWA，Service Worker 离线缓存已写但本评审环境不允许注册，未验证。可用材料：实际走查两轮（834×1112 平板视口）、代码定位、27 项规则测试、60 天调度仿真。没有真实儿童使用数据。本评审未修改任何源码。

## 1. 一页结论

- **最强的一处**：学习引擎诚实。独立认对与借提示分开记分、换词再认防止"记卡片位置"、描红与凭记忆写分开、失败不惩罚（core.js `completeSession`、`recordWriting`；走查 H1/H8 证实）。
- **最致命的一处**：没有阻断级问题。最接近的是首次使用末尾连续两个弹窗（摸底介绍、摸底结果），把刚建立的"小岛"情绪切回对话框，且摸底介绍重复了引导第三屏已做过的试听。
- **最值得先做的一件事**：引导结束后直接进入摸底第一题，摸底结果改成首页上的一行字；两处弹窗都去掉。改动小，影响的是每个孩子的第一分钟。

## 3. 问题清单

**Q1 引导末尾的两个弹窗**
- 现象：点"出发"后弹摸底介绍（含重复的试听）；摸底结束再弹结果。
- 影响：首次体验的情绪连续性；D2 可理解性（孩子刚学会"一个按钮往前走"，突然要在弹窗里二选一）。
- 根因：`finishWelcome` 调用 `startIntro()`；`placementNext` 用 `showModal` 报告结果。
- 改法：引导"出发"直接进入摸底第一题（左上角保留"从基础开始"）；结果改为首页主按钮上方一行："你已经认识：上。明天再来确认。"
- 改动量：S。验证：冷启动到第一题之间弹窗数 = 0；摸底后首页出现该行。

**Q2 完成页主按钮早于内容可点**
- 现象："今天到这里"第一帧可点，成果句 0.5–1.2 秒内才出现。
- 影响：D7 奖励感知——成果句是"能力感"的来源，被跳过就只剩星星数字。
- 根因：按钮无延迟，`countUp` 和成果句有延迟。
- 改法：按钮与星星同时出现（延迟 1.2 秒）；减少动态效果时即时出现。
- 改动量：S。验证：录屏确认按钮在成果句之后出现；减少动态效果下即时。

**Q3 下一个目标卡显示 "7 / 5"**
- 现象：星星超过价格时显示超额数字。
- 影响：D1 颜色/信息编码——数字承担了无意义信息。
- 改法：够了只显示"可以换啦"，隐藏分数；进度条封顶 100%。
- 改动量：S。验证：星星 ≥ 价格时卡片无数字。

**Q4 家长页说明框对比度 3.33:1**
- 现象：`.parent-note` 文字 #7c899e 在 #f5f8fc 上。
- 影响：D1（家长侧）。
- 改法：文字改 #5f6c80（≈4.9:1）。
- 改动量：S。验证：对比度计算 ≥ 4.5。

**Q5 引导第三屏的键盘遮挡（未验证）**
- 现象：名字输入框获得焦点时平板软键盘弹出，"出发"按钮可能被遮住。
- 影响：D3 可达性，首次使用。
- 改法：输入框聚焦时把页面滚到按钮可见，或把"出发"放在输入框上方。
- 改动量：S。验证：真机 iPad/Android 各试一次。本评审环境无软键盘，列为需验证而非结论。

**Q6 离线缓存未经真机验证**
- 现象：sw.js 已部署，注册在内置浏览器失败。
- 影响：D4 容错（无网时写字关卡能否用）。
- 改法：不改代码；真机飞行模式验证一次。
- 改动量：—。验证：飞行模式下能进写字页并出笔顺。

## 4. 自我迭代结论

| 第一轮假设 | 第二轮结果 |
|---|---|
| 两次答错后第二次没有出现提示（第一轮日志显示"再看看"） | **推翻**：第一轮脚本点击了已被替换的旧按钮，不是产品问题；重做后两次错 → 行内提示"是 木，mù，木头"，`hinted=true` |
| 借提示答对后也会自动前进，可能跳过阅读 | **推翻**：借提示答对停在原页，需手动点"写一写"；只有独立答对才 1.6 秒自动前进 |
| 写字求助一开始就显示，等于邀请放弃 | **推翻**：开始时不显示；写错 1 笔不显示，写错 2 笔显示 |
| "今天先写到这里"会让这个字消失 | **推翻**：`writing.木.pending=true`，下次写字优先排它 |
| 换词再认没有声音退路 | **部分推翻**：没有"听不到声音？"按钮，但有"听句子"和"我还不确定"，后者直接给出字 |
| 引导末尾两个弹窗 | **证实** |
| 完成页按钮早于内容 | **证实**（截图 1.8 秒时成果句仍在淡入，按钮已在） |
| 儿童可点元素有 <44px 的 | **推翻**：扫描首页、学习卡、认字页，只有品牌链接 42px |

## 5. 优先级路线图

- **P0 立即做**：无。
- **P1 下一迭代**：Q1（去掉两个弹窗）→ Q2（完成页按钮延后）。Q1 先做，因为它改变 `finishWelcome` 与 `placementNext` 的流转，Q2 独立。
- **P2 观察**：Q3、Q4 顺手改；Q5、Q6 需要真机，建议下次 Cindy 用平板时各试一次。

## 6. 不建议做的事

- **连续打卡/断签提醒**：会把"来不来"变成焦虑；现有"这周来了 N 天"是累计不是连续，保留。
- **排行榜、好友、分享**：目标年龄不适合比较；产品只和自己比。
- **宠物饥饿/生病**：惩罚式回访钩子；小岛装饰只会增加不会减少，保留。
- **每题计时、速度分**：会放大她"急着完成"的习惯。
- **更多引导屏**：现在 3 屏 3 次点击；再加只会推迟第一次成功。
- **每次点击都有音效**：目前只在对、写完、完成三处出声，足够；更多会掩盖语音线索。
- **给家长发周报/邮件**：需要服务端和持续投入；家长页"这一周"已覆盖。
