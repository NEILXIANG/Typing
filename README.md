# Cindy 的汉字小岛

给 8 岁、中文口语流利但认字和写字需要巩固的 Cindy 做的平板网页。内容按一年级基础到二年级进阶组织，首版有 500 个去重汉字、28 个主题，每字有拼音、两个词、例句和本地笔顺数据。它是家庭练习课程，不声称与某一版小学教材的课次完全一致。

## 不可违背的原则

每次改动前对照这份清单；任何新功能如果违反其中一条，就不做。

1. 不做连续打卡、排行榜、和别的孩子比较；只说"这周来了几天"。
2. 不按速度计分，不放倒计时。
3. 答错和写错不惩罚：没有红叉、不扣星星、孩子界面不显示错误次数。
4. 独立完成和借助提示分开记录；只有独立认对才算进"记得牢"。
5. 认字和写字分开排进度，写字永远可以降级或"今天先写到这里"。
6. 每天有明确的结束：总步数有上限，完成页之后没有"再来一轮"。
7. 奖励都对应真实的学习（植物＝记得牢的字，小客人＝走完的主题，字的魔法＝写出的字），不加新的积分或收集系统。
8. 孩子的页面一屏一件事，横竖屏都不用滚动。
9. 体验结论要在真机（家里的华为平板）上确认，电脑模拟不算数。

## 本机和同一 Wi-Fi 的平板

需要 Node.js 18 或更新版本。项目没有需要安装的 npm 依赖。

```bash
cd /Users/neilxiang/Documents/Typing
npm run dev
```

电脑打开 `http://localhost:4173`。Android 平板或 iPad 与电脑在同一 Wi-Fi 时，打开 `http://电脑的局域网IP:4173`；电脑防火墙需要允许 Node.js 接受局域网连接。日常使用可在平板直接打开已部署的 [Cloudflare 网页](https://typing.neilxiang.workers.dev/)，无需让电脑一直开机。

也提供 `public/offline.html`：运行 `npm run build` 后，保持整个 `public` 文件夹的目录结构，将其复制到设备上并尝试用浏览器打开 `offline.html`。页面代码、插画和 500 字笔顺数据都在本地。某些移动浏览器会限制 `file://` 页面的本地存储或脚本；因此 Android/iPad 日常使用更推荐网页网址。浏览器朗读取决于系统安装的中文语音；部分声音需要联网。背景音乐由浏览器即时合成，不需要网络或 API 密钥。

## 学习规则

- 每天先做到期的复习，再用剩下的时间学新字：一天总共约 20 步（家长页可选 16 / 20 / 24 步，约 8 / 10 / 12 分钟）。新字目标 2–5 个由家长设置（默认 3 个），每天至少 1 个；复习多的日子新字自动变少，复习少的日子补满目标。还不牢的到期字优先，记得牢的字只做一道快速换词再认；放不下的复习顺延到明天。隔天没学不累计新字任务。复习间隔 1/3/7/14/30/60/90 天。形近字（如森/林、晴/清）不会在同一天一起作为新字出现。
- 每个字有一个难度分（笔画数 + 形近字数量），同一主题里先学简单的字；重点书写优先安排前几天已经认对过、而且难度低的字，没有时才写当天的新字。孩子的页面上不出现年级，"一年级 / 二年级"只是家长页里内容范围的参照。
- 每天重点描红 1–2 个字；描红只记作练过，不等于已经能默写。
- 学习时有插画、拼音、词语和例句。独立认字时隐藏插画与拼音，先听词找字，再用词句复认。答错或看过提示后，本轮不计独立掌握。
- 同一个字在三个不同日期独立认对，才进入“记得牢”。星星和个人挑战榜按完成质量记录，不按速度，也不虚构别的孩子的排名。
- 写字单独排进度：没写完的字会在之后的日子优先回来。写字可以逐级降低难度（凭记忆写 → 描红 → 跟着提示写 → 一笔一笔看），也可以"今天先写到这里"，都不扣星星。描红之后的另一天凭记忆写出来，才算"能独立写"。
- 写字判定对孩子放宽：写错第一笔就提示从哪里起笔；第一次描一个三笔以上的字时，小兔先写第一笔，孩子接着写。
- 第一次使用只有一屏欢迎（点"出发"，小兔问好），然后做最多 9 题的自适应摸底：从简单的开始，不显示对错；至少做满 5 题后，连续三次没认出才提前结束。已经认识的字跳过新学，第二天复习确认。
- 首页的"生活寻字"只用已学过的字，场景包括超市、中餐馆、标识、视频通话、节日等。做到后记一次"生活里用过"，每天一次，不加星星；这不代表已经记住。
- 页面只有"今天 / 我的小岛 / 家长"三个去处。首页只有一个"开始"按钮，复习、新字、写字、换词再认自动排成一条线；学习时收起导航。故事、偏旁配对、学习地图和字库放在"我的小岛 → 自由探索"，随时可以休息并继续；一天的最后是一轮"找朋友"（字和它的部首配对）。中途"休息一下"时，已经认对的字先结算，回来接着做不会重复给星星。
- 完成页只有小岛、一两句今天做到的事和获得的星星，然后结束。一个字第一次进入"记得牢"时额外 +2 星；星星和商店只在"我的小岛"里出现。商店有城堡（150 星）和火箭（260 星）两个长期目标。家长页可以改孩子的名字。安装到主屏幕后，页面、笔顺、插画和字体会缓存，没有网络也能学习（Service Worker）。
- 小岛是活的：每 5 个记得牢的字自动长出一株植物；写出的字会变成岛上的一幅画或一块字牌；一个主题的字全部见过后，那个主题的小动物搬到岛上；天空跟着时间和季节变化。首页可以在两个主题岛里选今天去哪个；每天学完小兔会留一封信（信箱在"我的小岛"）。
- 500 个字的字音、词语、例句以及问候、故事都有预先录好的声音，平板不用装中文语音包；只有小兔的信用平板自带的朗读。

家长页首屏只有"今天练了什么"和"明天怎么陪"；"这一周"、"可以一起练的地方"（记忆分层、常需多试几次的笔画、易混偏旁、借提示和降级）、学习量与难度（新字量、书写量、每天多长、起点范围、名字）、声音和备份都折叠在下面，需要时再展开。每天的详细记录也从家长页进入。完整的设计说明见 [docs/PRODUCT_DESIGN.md](docs/PRODUCT_DESIGN.md)。进度保存在**当前设备的当前浏览器**；不同网址、设备或浏览器不会自动同步。建议定期导出备份。导入备份会替换当前浏览器的进度。

## 验证和构建

```bash
npm test
npm run build
```

`npm test` 检查学习排程、复习、独立掌握、积分和备份规则。`npm run build` 检查课程、插画文件、笔顺文件与脚本，并生成离线入口。网页主页位于 `public/index.html`，无需服务端数据库。

## Cloudflare 部署

此文件夹已关联 [NEILXIANG/Typing](https://github.com/NEILXIANG/Typing)。后续修改如要用命令行上传，在本文件夹运行：

```bash
git add .
git commit -m "Update Cindy's Hanzi island"
git push
```

当前使用 **Cloudflare Workers 静态资源**，正式地址为 https://typing.neilxiang.workers.dev/ 。`wrangler.jsonc` 指向 `./public`。推送 GitHub 不会自动更新这个网址；每次修改后运行：

```bash
npm run build
npx wrangler deploy
```

首次在新电脑运行需通过 Wrangler 登录同一个 Cloudflare 账户。官方参考：[Workers 静态资源](https://developers.cloudflare.com/workers/static-assets/binding/)；若以后希望 GitHub 推送后自动发布，可在 Cloudflare 控制台另行配置构建与部署。
